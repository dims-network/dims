# Screenshots for the walkthrough

Drop the files here under exactly these names and
[`tutorial.md`](../../tutorial.md) picks them up — until then each one
renders as a dashed panel saying what belongs in it, so the page is readable
with none of them taken.

**How to take them.** Browser window **1280 × 800**, no bookmarks bar, default
zoom, light theme. Capture the wizard's own panel rather than the whole screen
where you can; include the step bar across the top on the wizard shots, because
it is how a reader keeps their place. Save as PNG. Use the example study
(ConvoConnect-Mini) so what is on screen matches what the page describes — real
data in a screenshot on a public page is a data-visibility decision, not a
convenience.

describes what you actually captured — several captions name specific times and
